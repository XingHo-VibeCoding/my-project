# message-filter-validation

## 用途
本 Skill 为消息捕捉推送项目提供**可复用的筛选交互校验**，用来验证前端筛选组件逻辑、移动端 UI 规范，每次改动筛选相关代码之后都可以调用本 Skill 做回归测试。

## 校验规则清单
1. 页面层级：筛选区、消息结果列表、清空重置按钮层级正常，元素无互相遮挡
2. 颜色字体：筛选输入提示文字、空状态提示文字符合项目 UI 规范
3. 卡片与按钮：筛选查询按钮、清空重置按钮、消息卡片点击响应正常
4. 移动端适配：手机端页面自适应，筛选输入框、下拉选项不会溢出屏幕边界
5. 修改前检查：修改筛选模块代码前，确认原有筛选功能未被破坏
6. 修改后验证：代码变更完成，必须跑通下面 3 种筛选场景

## 必测筛选场景（Day12 硬性要求）
1. **有结果**：输入匹配关键词，成功返回符合条件的捕捉消息列表
2. **无结果**：输入不存在的关键词，页面正确渲染空状态「暂无匹配消息」
3. **清空恢复**：点击清空筛选按钮，筛选条件重置，页面恢复展示全部原始消息

## 调用方法
1. 将 `SKILL.md` 放置项目根目录
2. 启动电脑服务端（电脑作为服务器），打开前端页面
3. 依次执行：输入有效关键词筛选 → 输入无效关键词筛选 → 点击清空重置
4. 保存本次调用记录，截图留存页面证据

## 成功标准
1. 三种筛选场景全部测试通过，交互无报错
2. 移动端布局适配正常，按钮可正常点击
3. 完整保存调用记录、页面截图证据

## 余力加练：可访问性检查
追加校验：筛选输入框、重置按钮支持键盘 Tab 跳转访问；空状态提示文案清晰可读，适配屏幕阅读器
